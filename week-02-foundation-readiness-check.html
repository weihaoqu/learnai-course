Challenge 1

GenAI foundations check

Use original scenarios to check the core Week 1 vocabulary before agent work begins.

A friend says, "The chatbot learned from the internet, so its answer must be more trustworthy than a web page." What is the best response?

LLMs can produce useful answers, but fluency is not authority. Important claims still need evidence.

Why do instructors describe AI as a general-purpose technology?

General-purpose technologies matter because they can be applied across many tasks and workflows.

A school wants incoming support emails automatically sorted into billing, tech help, and advising queues. Which design best matches that goal?

Automation usually means an LLM is embedded in a software workflow with the right system access and review rules.

Which description best matches generative AI?

Generative AI is named for generating new content, including text and media.

A chatbot answer appears on screen one piece at a time. What is the best simplified explanation?

Challenge 2

GenAI applications check

Check whether students can choose good prompts, realistic LLM tasks, and verification moves.

10 pts

A club asks AI, "Write copy for our new granola bar." Which revision gives the model the best chance to help?

Useful writing prompts include context, purpose, audience, tone, constraints, and output size.

Which set of tasks is realistic for an LLM assistant in this course?

LLMs are useful for many language tasks, but they do not become credentialed humans or automatic authorities.

You want grammar and style feedback on an essay draft. What is the best prompting workflow?

Prompting is iterative: try, inspect, clarify, and try again.

A student asks a plain chatbot to summarize this morning's top campus news, but gives no links or articles. What is the main problem?

Current facts require current sources or tools; model memory may stop at a training cutoff.

An assistant gives you a polished quote attributed to a famous inventor for a presentation. What should you do before using it?

Quotations are easy to hallucinate. Verify the source before publishing or presenting.

Challenge 4

Label the agent loop

Map each transcript line to the five-block model from Week 2.

10 pts
Student: Explain what files are in this project. Do not edit anything yet.
Agent sees project instructions, recent messages, and the current folder path.
Agent decides it should inspect the file tree before explaining the project.
Agent lists files and reads README.md without editing anything.
Student checks whether any files changed and whether the explanation names real files.
Input

The user's goal and constraints.

Context

History, files, rules, and visible information.

Model

The LLM selects a likely next action or response.

Tool loop

The agent reads, searches, edits, runs, observes, and loops.

Human review

The person inspects output, evidence, permissions, and changes.

Agents are useful because they can act. That also means the next action matters.

8 pts

A summary needs context first. Editing or deploying is outside the task.

Task: "Fix this typo in one slide title." The file is known.

Good agent work is scoped: inspect, change the minimum, then review.

Task: "Find the latest install command for Codex." Your memory may be stale.

Current install steps are time-sensitive; use current official docs.

Task: "Delete whatever files are unnecessary." The request is broad and risky.

Risky or destructive actions require clarification and explicit approval.
