Week 6: AI Media Generation
Slide 1
60-minute media lab

AI media is useful when it improves communication.

Today we use ChatGPT image generation as the required creative path, but the class goal is bigger: define a visual purpose, generate or critique an asset, integrate it into a slide or app, and document AI use.

In class

Build a visual brief, repair image prompts, critique sample outputs, and prepare a project asset packet.

Tool reality

Generation can take minutes or hit rate limits, so critique and presentation integration are the guaranteed activities. The access-blocked packet counts when it includes the brief, prompt, and critique.

Deliverable

A final image asset or access-blocked substitute with prompt, critique, alt text, disclosure, and usage context.

Pacing: 5 minutes. Stress that image generation is not decoration; the image has to do a communication job.
Source boundaries

Tool docs show capability. Class rules define acceptable use.

Use today

  • OpenAI says ChatGPT Images can create new images and edit existing images in ChatGPT.
  • OpenAI Academy emphasizes clear prompts, iteration, uploaded image references, and care with text-heavy visuals.
  • ChatGPT can also interpret uploaded images, with limitations.

Guardrails

  • Do not trust generated media as evidence.
  • For this class, avoid real-person likenesses, private photos, school logos, brands, copyrighted characters, and living-artist imitation unless the instructor approves the specific educational use.
  • OpenAI reports provenance/watermarking signals, but students still disclose AI use because signals may not survive export, screenshots, compression, or reposting.

Concept bridge

How a prompt steers an image.

A media model does not paste pictures from memory. A useful mental model is: text becomes direction, then the image is refined step by step.

Prompt
->
Text meaning
->
Denoise
->
Guidance
->
Final image

CLIP idea

Text and images can be compared in a shared meaning space, so prompts can point generation toward the intended concept.

Diffusion idea

Training teaches the model to remove noise from noisy examples. Generation starts from noise and refines the image step by step under prompt guidance.

Guidance idea

Prompts can change the denoising direction. Positive wording emphasizes wanted features; tools with negative prompts can steer away from unwanted features.

Pacing: 3 minutes. Keep this conceptual. Do not teach DDPM or DDIM math in the core 60-minute lab; the goal is to make prompt repair and negative prompts less mysterious.

52-55 min

Disclosure is still required even if provenance signals exist.

Provenance helps

OpenAI reports that generated images include C2PA metadata and SynthID watermarks. These are useful signals for provenance.

Disclosure still matters

Metadata and signals can be lost or unavailable after export, screenshots, compression, editing, or reposting. For class, students write a disclosure sentence and keep prompt history.

Disclosure draft: I used ChatGPT to generate a conceptual image for [slide/app/poster purpose]. I revised the prompt for [specific changes], checked for misleading realism/privacy/copyright/accessibility risks, and used the image as illustration rather than evidence.
Project asset packet

Build the AI media asset packet.

This packet is the homework skeleton and the exit ticket skeleton.

Homework rubric

What counts for Week 6?

Brief

Purpose, audience, medium, subject, composition, style direction, and constraints are clear.

Final prompt

The prompt is specific enough to reproduce the intended visual direction.

Image or substitute

Submit the image/screenshot, or an access-blocked substitute plus critique of a sample output.

Critique

Explain one rejected or revised output using concrete visual criteria.

Accessibility

Include alt text, contrast/readability check, and image-only information check.

Ethics and disclosure

Address privacy, likeness, copyright/style boundaries, provenance, disclosure, and usage context.

Homework

Due before Week 7.

Create one asset

Use ChatGPT to create one image asset for a course presentation, web app mockup, poster, or final project. Use non-sensitive content only.

If access fails

Submit the full brief and final prompt, critique the deck's sample output, then generate later before the due date if access becomes available. The instructor can approve equivalent completion if access remains unavailable.

Submit packet

Brief, final prompt, image/screenshot or access-blocked substitute, critique paragraph, alt text, disclosure, and where the image will appear.

Class rule

Do not use private photos, real-person likenesses, school logos, brands, copyrighted characters, living-artist imitation, or deceptive photorealistic evidence unless the instructor approves the specific educational use.
