Hour 1 question

How does text become meaning?

A transformer does not start with human understanding. It starts with tokens, turns them into numerical representations, and repeatedly updates those representations using context.

text -> tokens -> embeddings -> context-updated representations -> next-token prediction
Step 1

Start with tokens.

The input sentence is split into pieces. The model never receives a human page of text; it receives a sequence of tokens.

The student opened the bank ...

The word "bank" is the problem. Is it money, a river edge, or something else? The token alone is not enough.

Step 2

Tokens become embeddings.

An embedding is a numeric representation of a token.

You can imagine it as a location in a meaning space. Nearby locations tend to share useful patterns, such as topic, grammar, role, or style.

river

Water, shore, flow, flood.

Nature direction

bank

Ambiguous before context updates it.

Needs context

loan

Money, account, interest.

Finance direction

After the video

The whole move is representation to probability.

A transformer repeatedly changes numeric representations, then converts the final representation into scores for possible next tokens.

1Token id

A piece of text becomes an index in the model vocabulary.

2Embedding

The index selects an initial vector representation.

3Attention

Vectors exchange useful context with other vectors.

4MLP block

Each vector is transformed by learned pattern detectors.

5Logits

The final vector becomes raw scores for vocabulary tokens.

6Softmax

Scores become probabilities, then one token is selected.

token -> vector -> updated vector -> logits -> probabilities -> next token
Quick check

What does temperature change?

Temperature changes how much the sampling process explores lower-scored tokens from the model's score distribution.

Lower temperature

More predictable. The highest-scored token dominates more often.

Higher temperature

More variety. Lower-scored tokens get more chance, which can help creativity or create nonsense.

Temperature affects sampling behavior after the model has already produced scores. It does not verify truth or update the model's learned weights.
Quick check

What is the most useful Week 2 mental model?

The key idea is repeated context updating, not a database lookup or truth-checking machine.
Hour 2 question

How does context change meaning?

Attention is one mechanism that lets tokens use information from other tokens. It helps the model update an ambiguous representation into a more useful one.

"bank" + "river" -> nature meaning
"bank" + "loan" -> finance meaning

Attention intuition

Attention routes useful information.

A token representation can borrow information from other tokens. The model is not reading like a person; it is updating numeric representations so the next-token prediction gets better.

token meaning
->
look at context
->
update representation
->
predict better
Repeated layers

One update is not enough.

Transformers stack many layers. Early layers may capture local grammar or simple relationships; later layers can combine richer patterns.

1Token

Initial chunk representation.

2Attention

Bring in relevant context.

3MLP

Transform features and patterns.

4Repeat

Build a better representation for prediction.

We do not need the math today. We need the direction: representation gets refined by repeated computation.

Hour 3 question

How can a model seem to know facts?

Some facts are reflected in the model's learned weights because they appeared in training patterns. But this is not the same as a verified database or a live source.

learned pattern != current evidence
Knowledge intuition

Facts can be encoded as learned patterns.

The model may complete common facts because training shaped its internal numbers.

That can be useful, but it also means factual recall depends on training data, model behavior, and context. It is not the same as opening a source.

Likely learned

The Eiffel Tower is in...

Needs evidence

Our class policy says...

Mental model

A fact is not a row in a database.

The video gives a toy picture: an MLP can detect a pattern in a token vector and write a useful direction back into that vector.

1 Token vector

The current vector carries many features from earlier layers.

2 Feature detector

A learned projection tests whether a pattern is present.

3 Nonlinear gate

A nonlinear function lets some signals through and dampens others.

4 Write-back update

A second projection adds a learned direction to the representation.

Good intuition

MLPs can act like learned feature detectors and updaters inside the transformer.

Important caveat

In real models, factual associations often appear distributed across many features and weights, not as one clean neuron per fact.

Failure mode

Fluent recall can become fluent invention.

If the model has enough pattern to sound plausible but not enough evidence to be correct, it may generate unsupported output.

Looks good

Confident tone, precise dates, professional formatting.

Still risky

No source, stale information, wrong local policy, invented citation.

generation step: useful draft
verification step: evidence before decisions
Quick check
