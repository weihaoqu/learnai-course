Part 1

Foundation check

Choose the safest answer. This score is a readiness signal, not a trick exam.

20 pts

A model gives a confident answer about a current scholarship deadline. What should you do before using it?

Decision-relevant facts need source verification.

You ask an agent to improve a document. Which instruction keeps the first step safest?

Agent delegation starts with scope, context, and permission boundaries.

A classmate wants to paste private survey responses into a chatbot. What is the best first response?

Privacy is decided before upload, not after the model receives the data.

An AI-generated chart looks clean, but the totals seem surprising. What should happen before presentation?

Data and media outputs need verification before they become evidence.

Which statement best protects academic integrity in an AI-assisted submission?

The submission must show human judgment, not just final output.

Choose a midterm direction

Part 3

Build the midterm brief

The brief turns a vague idea into a scoped task an agent can help with.

20 pts

Brief standard

  • Specific problem and audience.
  • Allowed inputs and disallowed data.
  • Clear output type, not a vague "make something."
  • One verification action before submission.
  • One statement of human judgment.
Part 4

Live agent run or transcript fallback

Use Claude Code/Codex if available. If setup or access fails, analyze the sample transcript with the same rigor.

20 pts
Select the permissions you would allow or reject before trusting the agent run.

Fallback transcript

Student: Help me create a local tutoring tracker. You can edit the project if needed. Agent: I will first inspect the folder and make a plan before editing. I may need approval before changing files. Agent: Proposed output: spreadsheet fields for student name, session date, topic, confidence rating, next action, and notes. Agent: Risk: student names are private. Use fake names or approved data. Agent: I can also add a claim that tutoring improves grades by 40%. Reviewer task: identify what was good, what was risky, what evidence is missing, and what human revision you would make.
